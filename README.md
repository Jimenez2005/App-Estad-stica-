# Análisis Estadístico Descriptivo (Streamlit)

## Ejecutar en tu computador
    pip install -r requirements.txt
    streamlit run app.py

## Publicar con un enlace con el nombre del proyecto
1. Sube esta carpeta a un repositorio de GitHub.
2. Entra a https://share.streamlit.io, elige "Create app" y selecciona el repositorio y `app.py`.
3. En "App URL" escribe el nombre, por ejemplo `analisis-estadistico`.
   El enlace quedará: https://analisis-estadistico.streamlit.app
